# Смена

Учёт рабочего времени для Android на Python (Kivy).

- «Пришёл» / «Ушёл»: смены пишутся в `data.json` на телефоне, время берётся с часов телефона.
- На главной показано, сколько отработано за текущий месяц (`чч:мм` и в минутах), заработок и количество смен. 1-го числа счётчик начинается заново, история сохраняется.
- Вкладка «Календарь» показывает годы как на iPhone: листаешь вниз, нажимаешь на месяц, потом на день.
- Ночная смена — та, что началась после 22:30 (или до 06:00) или ещё шла в 22:30. Она отмечается во всех днях, которые затронула. Часы делятся по дням в полночь.
- Уведомления приходят после 8 и 12 часов смены, даже если приложение закрыто: их отправляет фоновый сервис.
- В настройках задаются ставка в € в час и включение уведомлений. Те же два вопроса задаются при первом запуске.

## Запуск на Windows

```bash
python -m venv .venv
.venv\Scripts\pip install "kivy[base]"
.venv\Scripts\python main.py --debug
```

`--debug` открывает справа панель: сдвиг времени (±10 мин, ±1 ч, ±1 день, ±1 месяц, +8/+12 ч), установка точной даты, генерация тестовых данных и очистка базы. Данные отладки хранятся в `debug_data/`.

Тесты: `.venv\Scripts\python -m unittest discover -s tests`

## APK

APK собирает GitHub Actions (`.github/workflows/build-apk.yml`) при каждом push в `main`. Готовый файл появится в разделе **Releases → latest → Smena.apk**. Это debug-сборка: при установке Android попросит разрешить установку из неизвестных источников.
